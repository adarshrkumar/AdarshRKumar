Intro: why naming conventions exist and why there are so many of them.

## The Cases

| Name | Example | Where you see it |
| ---- | ------- | ---------------- |
| camelCase | `myVariableName` | JavaScript variables and functions |
| PascalCase | `MyClassName` | Classes and components |
| snake_case | `my_variable_name` | Python, Rust, SQL columns |
| SCREAMING_SNAKE_CASE | `MY_CONSTANT` | Constants and environment variables |
| kebab-case | `my-file-name` | URLs, CSS classes, file names |
| SCREAMING-KEBAB-CASE | `MY-HEADER-NAME` | Rare (also called COBOL-CASE) |
